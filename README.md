# Hospital AI Assistant

AI-powered Hospital Management System built with FastAPI and Groq AI.

## Features

* User Authentication
* Doctor Management
* Patient Management
* Appointment Booking
* PDF Upload and Reading
* AI Chatbot using Groq
* Retrieval-Augmented Generation (RAG)

## Tech Stack

* Python
* FastAPI
* SQLite
* Groq API
* Sentence Transformers
* Uvicorn

## Installation

```bash
pip install -r requirements.txt
```

## Run Project

```bash
uvicorn app.main:app --reload
```

## API Documentation

```text
http://127.0.0.1:8000/docs
```
